# Portfolio de cursos

Use esta pasta para documentar cursos existentes, cursos em desenho e criterios de portfolio.

## Objetivo operacional

A Pandora busca chegar a 4 cursos presenciais rodando por mes, com portfolio de 4 cursos diferentes e vendas mensais estaveis.

## O que registrar por curso

- Nome do curso.
- Publico-alvo corporativo.
- Problema de negocio que resolve.
- Resultado esperado para participantes e empresa.
- Estrutura presencial.
- Pre-requisitos de entrega.
- Materiais comerciais disponiveis.
- Status: ideia, validacao, pronto para venda, vendido, pausado.

## Criterios de priorizacao

- Demanda comercial observada.
- Capacidade de entrega presencial com qualidade premium.
- Clareza do comprador e do problema corporativo.
- Reuso em empresas medias e grandes.
- Contribuicao para a meta de 4 cursos por mes.
