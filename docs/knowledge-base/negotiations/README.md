# Negociacoes

Use esta pasta para registrar oportunidades comerciais e historico de follow-up.

## Padrao de arquivo

`aaaa-mm-nome-da-empresa.md`

Exemplo: `2026-09-acme-industria.md`

## Checklist de criacao

- Copiar `../templates/negotiation-record.md`.
- Preencher status, dono, data e proxima acao.
- Registrar fatos confirmados e hipoteses separadamente.
- Linkar evidencias disponiveis.
- Atualizar o mesmo arquivo a cada evento novo.
