# Decisoes executivas

Use esta pasta para registrar decisoes que alteram direcao, prioridade, portfolio, posicionamento, vendas ou entrega.

## Padrao de arquivo

`aaaa-mm-dd-tema-da-decisao.md`

## Campos minimos

- Decisao.
- Dono da decisao.
- Contexto.
- Opcoes consideradas.
- Criterio usado.
- Riscos e trade-offs.
- Data de revisao.

## Regra

Decisoes que criam compromisso externo, preco, parceria ou promessa sensivel precisam de aprovacao explicita de Mario antes de serem tratadas como finais.
